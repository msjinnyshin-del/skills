# 홍보 전략 기획 가이드

## PR 전략 수립 프레임워크

### PESO 모델
홍보 전략은 네 가지 미디어 유형을 통합해야 한다.

| 유형 | 설명 | 예시 |
|-----|------|------|
| **P (Paid)** | 비용 지불 채널 | 광고, 스폰서, 인플루언서 유료 협찬 |
| **E (Earned)** | 자연 획득 노출 | 언론 보도, 바이럴, 리뷰 |
| **S (Shared)** | 공유 기반 채널 | SNS, 커뮤니티, 입소문 |
| **O (Owned)** | 직접 보유 채널 | 블로그, 뉴스레터, 유튜브, 웹사이트 |

---

## 홍보 전략 기획서 구성

### 1단계: 현황 분석

```
■ 브랜드 현황
- 현재 인지도 수준 (알려진 정도)
- 주요 타깃 고객층
- 경쟁사 홍보 활동 현황

■ SWOT 분석
- 강점(S): 우리만의 차별화 요소
- 약점(W): 홍보에서 불리한 점
- 기회(O): 활용 가능한 트렌드/이슈
- 위협(T): 경쟁사, 부정적 이슈 가능성
```

### 2단계: 목표 설정 (SMART)

```
■ 정량 목표 예시
- 3개월 내 언론 보도 20건 이상
- SNS 팔로워 10,000명 → 15,000명 증가
- 브랜드 검색량 월 50% 증가
- 웹사이트 유입 PR 채널 비중 20% 달성

■ 정성 목표 예시
- "혁신적" 또는 "신뢰할 수 있는" 브랜드 이미지 구축
- 업계 전문 미디어 정기 기고 확보
- 대표자 사업 전문가 포지셔닝
```

### 3단계: 핵심 메시지 개발

```
■ 메시지 피라미드
       [브랜드 핵심 메시지 - 1문장]
              /         \
    [서브 메시지 1]  [서브 메시지 2]  [서브 메시지 3]
    (근거/증거)      (근거/증거)      (근거/증거)
```

**핵심 메시지 작성 원칙:**
- 1문장, 20자 이내
- 차별화 포인트 명확
- 타깃의 언어로 작성
- 모든 홍보 채널에서 일관되게 사용

### 4단계: 채널 전략

#### 채널별 역할 정의
| 채널 | 주요 역할 | 게시 빈도 |
|-----|---------|---------|
| 블로그/뉴스룸 | 심층 콘텐츠, SEO | 주 1~2회 |
| 인스타그램 | 비주얼 브랜딩, 감성 소통 | 주 3~5회 |
| 링크드인 | B2B 신뢰도, 업계 전문성 | 주 2~3회 |
| 유튜브 | 스토리텔링, 제품 설명 | 월 2~4회 |
| 카카오채널 | 프로모션, CRM | 주 1~2회 |
| 언론 배포 | 공식 발표, 신뢰 구축 | 이슈 발생 시 |

### 5단계: 콘텐츠 캘린더

```
월간 홍보 콘텐츠 계획 (예시)

1주차: 신제품 출시 → 보도자료 + SNS 동시 발행
2주차: 사용자 스토리/후기 콘텐츠
3주차: 업계 인사이트/트렌드 포스팅 (전문성 강화)
4주차: 이벤트/프로모션 공지
```

### 6단계: KPI 측정

#### 트래킹 지표
```
■ 미디어 노출
- 보도 건수 (월별/분기별)
- 도달 독자 수 (Reach)
- 긍정/부정/중립 논조 비율

■ 디지털 성과
- SNS 팔로워 증가율
- 게시물 인게이지먼트율 (좋아요+댓글+공유/노출)
- 웹사이트 PR 채널 유입 수
- 브랜드명 검색량 (Google Trends, 네이버 트렌드)

■ 비즈니스 임팩트
- 보도 후 문의/가입 증가율
- 캠페인 기간 중 전환율 변화
```

## 위기 커뮤니케이션 기본 원칙

### 골든타임: 사건 발생 후 2시간 이내 첫 대응

```
■ 위기 대응 순서
1. 사실 파악 (내부 확인)
2. 초기 입장 발표 (인지 + 대응 중 알림)
3. 공식 입장 문 발표 (24시간 이내)
4. 사후 조치 발표 (1주일 이내)

■ 위기 대응 문구 원칙
- 사실이 확인된 것만 발표
- 피해자 중심 공감 먼저
- 책임 회피 발언 절대 금지
- 향후 재발 방지 조치 명시
```

## 브랜드 보이스 & 톤 가이드

### 어조 설정 기준
| 브랜드 유형 | 권장 어조 | 예시 키워드 |
|-----------|---------|----------|
| 스타트업/IT | 친근하고 활기차게 | "함께", "더 쉽게", "바꿉니다" |
| 금융/법률 | 신뢰감 있고 명확하게 | "안전한", "정확한", "믿을 수 있는" |
| 뷰티/패션 | 감각적이고 감성적으로 | "특별한", "당신만의", "아름다운" |
| 식품/라이프 | 따뜻하고 친근하게 | "맛있는", "건강한", "행복한" |
| B2B/엔터프라이즈 | 전문적이고 데이터 중심 | "효율", "성과", "최적화" |
