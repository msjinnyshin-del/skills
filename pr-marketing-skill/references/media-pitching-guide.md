# 미디어 피칭 가이드

## 미디어 피칭이란?

기자·에디터·인플루언서에게 보도 아이디어를 제안하는 커뮤니케이션.
보도자료 배포와 달리, 특정 미디어에 맞춤화한 1:1 제안이다.

---

## 피칭 이메일 구조

```
제목: [기사 아이디어를 압축한 한 줄 — 뉴스 가치 강조]

안녕하세요, [기자 이름]님.

[1~2문장: 기자의 최근 기사/관심사 언급 → 개인화 포인트]

[1~2문장: 핵심 아이디어 요약 — 왜 독자에게 흥미로운가?]

[2~3문장: 뒷받침 데이터 또는 사례]

이와 관련해 [인터뷰 제안 or 보도자료 발송 or 단독 제보] 의향이 있으시다면 
[날짜]까지 회신 주시면 감사하겠습니다.

추가 자료 첨부: [보도자료 / 데이터 시트 / 이미지]

[담당자명]
[직책 | 회사명]
[연락처]
```

## 미디어 리스트 전략

### 매체 분류 기준

| 분류 | 특징 | 적합한 보도 유형 |
|-----|------|----------------|
| 종합 일간지 | 파급력 최대, 게재 기준 높음 | 대형 투자, 사회적 이슈, 대기업 |
| 경제지 | 비즈니스 독자층, B2B 효과 | 창업, 투자, 파트너십, 실적 |
| 전문지/IT 매체 | 업계 타깃 독자, 깊이 있는 보도 | 기술 특징, 업계 트렌드 |
| 지역 매체 | 지역 독자, 로컬 이슈 강세 | 지역 행사, 로컬 서비스 |
| 인터넷 신문 | 빠른 배포, 포털 노출 용이 | 빠른 뉴스, 이벤트 |
| 유튜브/팟캐스트 | 영상 콘텐츠, MZ세대 도달 | 브랜드 스토리, 창업가 인터뷰 |
| 인플루언서 | 팔로워 신뢰도, SNS 확산 | 제품 체험, 라이프스타일 |

### 타깃 매체 선정 기준
1. **독자층 일치**: 우리 타깃 고객이 읽는 매체인가?
2. **이전 보도 유형**: 비슷한 기업/주제를 다룬 적 있는가?
3. **담당 기자 전문성**: 우리 분야를 잘 아는 기자가 있는가?
4. **포털 연동**: 네이버·다음 뉴스에 연동되는가?

## 피칭 타이밍 전략

### 최적 발송 시간
- **요일**: 화요일~목요일
- **시간**: 오전 9시~10시 (마감 전 여유 있을 때)
- **피해야 할 시기**: 월요일 아침, 금요일 오후, 공휴일 전날

### 뉴스 훅 활용
| 시기 | 연계 가능한 이슈 |
|-----|---------------|
| 연초 (1~2월) | 신년 전망, 트렌드 예측, 계획 발표 |
| 봄 (3~4월) | 신학기, 봄 시즌 제품, 인사이동 |
| 여름 (6~8월) | 여름 특수, 방학 이벤트, 휴가 관련 |
| 가을 (9~10월) | 추석 시즌, 신제품 시즌 |
| 연말 (11~12월) | 연말 결산, 올해의 성과, 내년 계획 |

## 팔로업(Follow-up) 전략

1. **첫 발송** → 3~5 영업일 후
2. **1차 팔로업**: "혹시 검토해보셨을까요?" (1~2문장 짧게)
3. **2차 팔로업**: 새 데이터나 앵글 추가 제안
4. **최대 2회**까지만. 그 이상은 역효과.

### 팔로업 이메일 예시
> 안녕하세요, 지현 기자님. 지난 [날짜]에 보내드린 헬스케어 앱 관련 제안 메일 혹시 검토해보셨을까요? 마침 이번 주 초에 앱스토어 헬스케어 부문 1위 달성 소식도 추가됐습니다. 관심 있으시면 편하신 시간에 10분 통화 부탁드려도 될까요?
